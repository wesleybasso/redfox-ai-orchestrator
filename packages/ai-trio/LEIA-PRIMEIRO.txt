--------------------------------------------------------------------
PASSO 1 - BASES
--------------------------------------------------------------------
1) Node.js (LTS): https://nodejs.org
2) PowerShell 7 : https://aka.ms/powershell
   Sempre use o "PowerShell 7" (icone PRETO), nao o azul antigo.

Testar:  node --version   e   $PSVersionTable.PSVersion

--------------------------------------------------------------------
PASSO 2 - INSTALAR OS CLIs (colar no PowerShell 7)
--------------------------------------------------------------------
TRIO (obrigatorio):
   npm install --global @tt-a1i/mco@0.11.0
   npm install --global @anthropic-ai/claude-code@2.1.185
   npm install --global @openai/codex@0.147.0
   npm install --global @google/gemini-cli@0.55.1

QUINTETO (opcional, adiciona Qwen + DeepSeek):
   npm install --global @qwen-code/qwen-code@0.21.6
   npm install --global --ignore-scripts @earendil-works/pi-coding-agent@0.84.0

--------------------------------------------------------------------
PASSO 3 - LOGIN / CHAVES (a parte que todo mundo esquece!)
--------------------------------------------------------------------
Claude Code -> digite:  claude   (faz login no navegador)
Codex       -> digite:  codex    (login conta OpenAI)
Gemini      -> pegue a chave no Google AI Studio e rode (troque SUA_CHAVE):
   [Environment]::SetEnvironmentVariable('GEMINI_API_KEY','SUA_CHAVE','User')
Qwen/DeepSeek -> NAO cole a chave a mao. Use o script no PASSO 5.

NUNCA cole sua chave em chat/IA. So no seu proprio PowerShell.

--------------------------------------------------------------------
PASSO 4 - INSTALAR A INTEGRACAO (dentro da pasta ai-trio-skills)
--------------------------------------------------------------------
Testar sem alterar nada:
   pwsh -NoProfile -File ./install.ps1 -WhatIf
Instalar de verdade:
   pwsh -NoProfile -File ./install.ps1
Depois FECHE e ABRA de novo a IA que for usar.

--------------------------------------------------------------------
PASSO 5 - (SO QUINTETO) CHAVE DO OPENROUTER
--------------------------------------------------------------------
Rode UM destes conforme a IA base que voce usa:
   Codex : pwsh -NoProfile -File "$env:USERPROFILE/.codex/skills/using-ai-trio/scripts/configure-openrouter.ps1"
   Gemini: pwsh -NoProfile -File "$env:USERPROFILE/.gemini/trio-scripts/configure-openrouter.ps1"
   Claude: pwsh -NoProfile -File "$env:USERPROFILE/.claude/skills/using-ai-trio/scripts/configure-openrouter.ps1"
Cole a chave quando pedir (a tela fica "em branco" ao digitar = normal).
Depois abra uma nova sessao.

Usar de verdade:
